# シフトログ

Googleカレンダーのバイトの予定を読み込んで、時給から給料を自動で計算するアプリ（シフトボード風）。
いくら貯まったか（受け取った・振込待ち）と、いくら貯まる予定か（シフト予定）がひと目でわかります。

- アプリ: https://maomax0427.github.io/shiftlog/
- iPhone: Safariで開いて 共有 → ホーム画面に追加

## できること

- **シフト** … 月のカレンダーに勤務先の色でシフトを表示。その月に働く分の給料（働いた／これから）
- **手入力** … ＋ボタンから。よく使うシフト（履歴）をタップで入力。スタンプボタンで「まとめて入力」
- **給料** … 年の見込み（受け取った・振込待ち・予定）、目標・扶養の壁までの残り、振込月ごとの金額
- **勤務先** … 時給（変更履歴つき）、締め日・給料日、深夜・残業手当、土日祝の時給アップ、交通費、休憩ルール

## しくみ

```
Googleカレンダー ──> Apps Script ──> アプリ（このリポジトリ）
                      │
          スプレッドシート「シフトログデータ」（勤務先・手入力シフト・全シフト一覧）
```

- 勤務先の「キーワード」が予定名に入っているものだけをシフトとして読み込みます
- カレンダーが正。手入力と同じ時間帯のカレンダーの予定があれば、カレンダーを優先します
- `apps-script/Code.gs` … カレンダーの読み込み・保存
- `calc.js` … 給料の計算、`app.js` … 画面、`demo.js` … お試しデータ

設定手順はアプリの「設定」タブに書いてあります。
